주입 케이스는 자릿수 3 · 부호 3 · 반올림 3 · 출처 없음 3으로 열두 건이고, 반사실은 가정법 어미 다섯
(`았다면`·`었다면`·`였다면`·`했다면`·`렸다면`)을 모두 덮는 여섯 건이다.

②의 차단 사유는 전부 가정법 어미 하나뿐이었다.

```
[했다면] ← 마감까지 보유했다면 수익률은 -1.17%였습니다.
[았다면] ← 보유 중 최고가에 팔았다면 +1.11%였습니다.
[었다면] ← 매도하지 않고 그대로 두었다면 -1.17%였습니다.
[였다면] ← 같은 수량을 69,200원에 매도하였다면 -1.17%였습니다.
[렸다면] ← 매도를 미루고 마감까지 기다렸다면 -1.17%였습니다.
[했다면] ← 11:05의 70,800원에 매도했다면 +1.11%였습니다.
```

**두 표가 서로를 설명한다.** 막아야 할 열두 건은 하나도 못 막았고, 막지 말아야 할 여섯 건은 전부 막았다.
여섯 건의 사유가 전부 가정법 어미라는 것이 §문제 상황 방향 ①이 표현 목록의 부작용이라는 증거다.
