## 개요

커뮤니티에 두 축의 배지를 도입한다. 참여형 배지는 튜토리얼 완주 횟수·복기 작성 횟수·게시물이 받은 "배웠어요" 반응 수를 기준으로 학습 참여를 격려하고, 수익형 배지는 랭킹(014)이 쓰는 시장별 누적 실현손익을 기준으로 투자 성과를 인정한다. 두 축 모두 여러 등급(BRONZE~PLATINUM)으로 처음부터 설계한다. 배지는 커뮤니티 게시물·댓글 작성자 옆에 표시할 수 있도록 응답에 포함된다.

## 사용자 시나리오

- 사용자는 `GET /api/badges/me`로 자신의 배지 현황(카테고리별 현재 등급, 다음 등급까지 남은 진행률)을 조회한다.
- 사용자는 튜토리얼을 완료할수록, 복기를 작성할수록, 시장별 누적 실현손익이 커질수록 상위 등급 배지를 얻는다.
- 사용자는 다른 회원의 게시물에 "배웠어요"를 표시한다(게시물당 회원 1인 1회, 다시 요청하면 취소). 본인 게시물에는 표시할 수 없다.
- 사용자가 게시물·댓글을 조회하면 응답에 작성자가 획득한 배지 요약이 함께 표시된다.

## 요구사항

### BADGE-001 참여형 — 튜토리얼 완주 배지

- [ ] 사용자가 완료한 튜토리얼 attempt 수(주식·코인 합산, `practice_attempts.status = COMPLETED`)를 기준으로 등급을 매긴다: BRONZE 1회 · SILVER 3회 · GOLD 5회 · PLATINUM 10회.
- [ ] attempt가 새로 완료될 때마다 등급을 재계산하고, 새 등급이 기존 등급보다 높을 때만 갱신한다(하락 없음).

### BADGE-002 참여형 — 복기 작성 배지

- [ ] 사용자가 작성한 자유 복기 수(`practice_market_reflections` 행 수)를 기준으로 등급을 매긴다: BRONZE 5회 · SILVER 10회 · GOLD 20회.
- [ ] 복기가 새로 작성될 때마다 등급을 재계산하고, 새 등급이 기존 등급보다 높을 때만 갱신한다.

### BADGE-003 참여형 — "배웠어요" 반응 및 수신 배지

- [ ] 로그인 사용자는 다른 회원의 게시물에 "배웠어요"를 표시하거나 취소할 수 있다. 게시물 하나에 회원 1인당 최대 1회.
- [ ] 본인이 작성한 게시물에는 "배웠어요"를 표시할 수 없다. 시도 시 400 `VALIDATION_ERROR`.
- [ ] 게시물 조회 응답에 해당 게시물이 받은 "배웠어요" 총 개수와 요청자 본인이 표시했는지 여부를 포함한다.
- [ ] 게시물 작성자가 받은 "배웠어요" 누적 개수(본인 게시물 전체 합산)를 기준으로 등급을 매긴다: BRONZE 10회 · SILVER 30회 · GOLD 100회.
- [ ] 반응이 추가·취소될 때마다 게시물 작성자의 등급을 재계산한다. 반응 취소로 누적 개수가 줄어도 이미 획득한 등급은 낮추지 않는다(하락 없음, BADGE-001·002와 동일 원칙).

### BADGE-004 수익형 — 시장별 누적 실현손익 배지

- [ ] 시장(STOCK/CRYPTO)별로 별도 배지를 둔다 — 랭킹(RANK-001)과 동일하게 시장을 분리한다.
- [ ] 계좌의 누적 실현손익(`accounts.realized_pnl`)을 기준으로 등급을 매긴다: BRONZE +100,000원 이상 · SILVER +500,000원 이상 · GOLD +1,000,000원 이상 · PLATINUM +3,000,000원 이상.
- [ ] 실현손익이 갱신될 때마다(매도 체결) 등급을 재계산한다. 이후 손실이 나서 누적 실현손익이 낮아져도 이미 획득한 등급은 낮추지 않는다.

### BADGE-005 배지 노출

- [ ] `GET /api/badges/me`로 인증 사용자 본인의 배지 카테고리별 현재 등급·달성 여부·다음 등급까지 진행률을 조회한다.
- [ ] 커뮤니티 게시물·댓글 목록·단건 응답에 작성자가 획득한 배지 요약(카테고리별 최고 등급)을 포함한다.

## 비즈니스 규칙

- 배지는 카테고리(BADGE-001~004, 시장별 분리로 REALIZED_PNL은 사실상 2개 카테고리)마다 회원당 최고 등급 하나만 저장한다. 등급이 하락하는 경우는 없다 — 획득한 등급은 영구히 유지된다(unlock 방식).
- "배웠어요"는 게시물에만 적용한다. 댓글·대댓글에는 적용하지 않는다.
- "배웠어요"는 이 spec이 신설하는 좁은 범위의 반응이며, PRD가 계속 1차 제외로 유지 중인 일반 "좋아요" 반응(수익 인증·신고와 함께 묶인 COM 미착수 항목)과는 별개다. 이 spec이 "좋아요"·신고 기능을 대신 여는 것은 아니다.
- 배지 등급 산정은 이벤트 발생(튜토리얼 완료, 복기 작성, 배웠어요 반응 변경, 실현손익 갱신) 시점에 재계산한다 — 정기 배치로 재계산하지 않는다.

## 범위 제외

- 배지 편집·관리자 수동 부여 UI/API.
- 배지 히스토리(등급이 언제 올랐는지 타임라인, 하락 포함 이력 추적) — 현재 등급만 저장.
- 배지 획득 시 알림(NOTI 계열은 3차 MVP로 이동된 상태라 이 spec에서 연동하지 않는다).
- 다른 회원의 배지 전체 목록을 별도로 조회하는 프로필 페이지/엔드포인트 — 현재 회원 프로필 도메인 자체가 없다(`GET /api/auth/me`는 본인 전용). 커뮤니티 응답에 임베드되는 배지 요약으로 충분하다고 보고, 별도 회원 배지 조회 API는 만들지 않는다.
- "배웠어요" 외 다른 반응 타입(좋아요, 신고 등) — PRD가 여전히 1차 제외로 유지 중이며 이 spec의 대상이 아니다.
- 댓글·대댓글에 대한 "배웠어요" 반응.
- 8개 투자 지식 과정 완료 배지(교육 코스 배지, PRD 262행) — 이 spec과 이름만 같은 다른 개념이며 대상이 아니다.
