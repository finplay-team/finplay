# OpenDART 고유번호(corp_code) 매핑 — 종목코드(instruments.symbol) = 8자리 corp_code
#
# ┌─ 이 파일은 지금 비어 있다. 값을 채우기 전까지 공시는 한 건도 수집되지 않는다. ─┐
#
# 왜 비워 두었는가.
#   corp_code는 규칙으로 만들 수 없는 DART 내부 식별자이고, 정본은 아래 API가 주는 corpCode.xml 하나뿐이다.
#   그 API는 crtfc_key(DART_API_KEY)를 요구하는데 이 값을 발급받기 전에 이 파일을 만들게 되어,
#   확인되지 않은 값을 적는 대신 비워 두고 채우는 방법만 남겼다.
#
#   추측으로 채우면 안 되는 이유가 "안 되면 0건이라서"가 아니다. corp_code는 8자리 숫자라 틀려도 형식이
#   맞으면 API가 200을 돌려준다 — 다만 그 값은 **다른 회사의 공시**다. 그러면 예외도 경고도 없이
#   삼성전자 카드에 남의 회사 공시가 근거로 붙고, 화면·LLM 입력·원문 링크까지 그대로 흘러간다.
#   매핑이 없어서 건너뛰는 것은 spec이 정한 정상 동작이지만(FEED-001 "매핑에 없는 종목은 건너뛴다"),
#   틀린 매핑은 조용한 오정보다. 그래서 빈 파일이 추측보다 낫다.
#
# 채우는 방법 (DART_API_KEY 발급 후 1회, 결과를 이 파일에 커밋한다)
#   1. corpCode.xml 내려받기 (ZIP으로 온다)
#        curl -sO "https://opendart.fss.or.kr/api/corpCode.xml?crtfc_key=$DART_API_KEY"
#        unzip -p corpCode.xml > CORPCODE.xml
#   2. V7 시드의 주식 16종목 symbol로 <stock_code>를 찾아 같은 <list>의 <corp_code>를 꺼낸다.
#      symbol은 6자리 종목코드다(예: 005930 삼성전자). stock_code가 비어 있는 <list>는 비상장이라 건너뛴다.
#   3. 아래 형식으로 16줄을 적는다. 확인한 날짜를 함께 남긴다.
#
# 형식
#   symbol=corp_code   (symbol 6자리, corp_code 8자리 숫자. # 로 시작하는 줄과 빈 줄은 무시)
#   예) 005930=00000000   ← corp_code 자리는 8자리라는 뜻일 뿐이다. 이 줄을 그대로 옮겨 적지 마라.
#   형식이 어긋난 줄은 기동 시점에 예외로 막는다 — 오타를 런타임까지 끌고 가지 않는다.
#
# 대상 16종목 (V7 시드, spec §C-7 instruments.stock-count)
#   005930 삼성전자        000660 SK하이닉스      373220 LG에너지솔루션   207940 삼성바이오로직스
#   005380 현대차          000270 기아            068270 셀트리온         035420 NAVER
#   005490 POSCO홀딩스     006400 삼성SDI         051910 LG화학           105560 KB금융
#   055550 신한지주        035720 카카오          012330 현대모비스       096770 SK이노베이션
