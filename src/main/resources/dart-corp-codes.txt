# OpenDART 고유번호(corp_code) 매핑 — 종목코드(instruments.symbol) = 8자리 corp_code
#
# 정본은 OpenDART가 주는 corpCode.xml 하나뿐이다. 2026-08-04에 그 파일을 받아
# V7 시드의 주식 16종목 stock_code로 조회해 채웠다 (상장사 3,981건 중 16건 일치, 누락 0).
#
# corp_code는 규칙으로 만들 수 없는 DART 내부 식별자다. 추측으로 채우면 안 되는 이유가
# "틀리면 0건이라서"가 아니다 — 8자리 숫자라 형식만 맞으면 API가 200을 돌려주는데
# 그 값은 다른 회사의 공시다. 예외도 경고도 없이 삼성전자 카드에 남의 회사 공시가
# 근거로 붙고 화면·LLM 입력·원문 링크까지 흘러간다. 매핑이 없어 건너뛰는 것은
# spec이 정한 정상 동작이지만(FEED-001) 틀린 매핑은 조용한 오정보다.
#
# 갱신이 필요할 때 (종목 추가·상장폐지·합병으로 corp_code가 바뀔 때)
#   1. curl -sO "https://opendart.fss.or.kr/api/corpCode.xml?crtfc_key=$DART_API_KEY"   # ZIP으로 온다
#   2. 압축을 풀어 CORPCODE.xml에서 stock_code로 찾아 같은 <list>의 corp_code를 꺼낸다
#   3. 아래 줄을 고치고 확인한 날짜를 이 머리말에 남긴다
#
# 형식
#   symbol=corp_code   (symbol 6자리, corp_code 8자리 숫자. # 로 시작하는 줄과 빈 줄은 무시)
#   형식이 어긋난 줄은 기동 시점에 예외로 막는다 — 오타를 런타임까지 끌고 가지 않는다
#
# 주의 — 시드의 종목명과 DART 등록명이 다른 경우가 있다 (005380: 시드 "현대차" / DART "현대자동차").
